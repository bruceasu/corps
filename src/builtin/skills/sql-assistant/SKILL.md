# SQL 助手 (SQL Assistant)

这是一个利用 **Skills Pattern** 实现的按需加载知识的 SQL 助手。它不会预先加载数据库的所有表结构，而是根据你的问题动态加载相关的元数据（Schema），然后生成并执行 SQL。

## 核心流程
1. **识别需求**：分析用户提出的数据库相关问题。
2. **加载元数据 (Load Metadata)**：调用 `sql-schema-loader` 获取相关表的结构和业务规则。
3. **生成 SQL**：基于获取到的 Schema 生成准确的 SQL 语句。
4. **执行查询**：调用 `mysql-client` 执行查询并返回结果。

## 适用场景
- 复杂数据库查询（多表关联）。
- 数据库结构庞大，无法一次性塞入上下文的场景。
- 需要遵循特定业务规则的查询。

## 示例
- "查询过去 30 天内订单总额最高的前 5 名客户。"
- "找出所有没有关联地址信息的活跃用户。"
